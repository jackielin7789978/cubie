# 網頁魔術方塊

公司技術分享用的單機版 3D 魔術方塊，支援 2×2、3×3、4×4 和三種視覺主題，桌機和手機都能玩。

使用 Vite、React、TypeScript 和 Three.js。

## 開始開發

在這個資料夾打開 Claude Code，輸入：

```
讀 CLAUDE.md 和 SPEC.md，從第 0 階段開始。
```

Claude 會先和你確認配色、設計和部署位置。確認完後，說「開始」，Claude 就會自主完成開發、驗證和部署。

## 文件

- `SPEC.md`：完整規格
- `CLAUDE.md`：給 Claude Code 的協作規則
- `DECISIONS.md`：設計與部署決定
- `PROGRESS.md`：開發進度
